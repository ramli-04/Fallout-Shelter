# Architecture before Phase 3.5

Main composes the Director dashboard and isolated SubViewport 3D world. SimulationManager owns fixed clock, seeded agents, five shelter records, admission, incidents, memories, rumors and results. CityMap supplies footprints and spawn slots; RoadRoutes is authoritative deterministic movement. RoadNavigation3D and NavigationAgent3D validate presentation paths on the same corridors. Coordinates maps simulation XY to 3D XZ at 0.1 scale. City3D creates geometry; Shelter3D only exists for present shelters. Camera rig supports diagonal orbit, pan, zoom and focus. Impact3D was a cosmetic fixed-center flash. ShelterState tracks doors, maintenance, supply and occupancy; impact previously only classified sheltered/exposed. No ten-day phase exists. LLMBridge serializes allowlisted AgentObservation private beliefs over localhost to the Python Ollama service, applies validated LLM actions and falls back to rules; metrics and traces are retained. assets/models is absent, so procedural assets are necessary. Existing historical tests include assumptions about the old map and cosmetic-only impact.
